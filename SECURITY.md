# Security policy

Please don't open a public issue for a security problem.

Report it privately instead:

- **GitHub:** [report a vulnerability](https://github.com/hawl3y/byebell/security/advisories/new) (Security tab → Report a vulnerability).
- **Email:** support@byebell.com

Include what you found, how to reproduce it, and what it affects. We'll reply as soon as we can and keep you updated until it's fixed.

This covers the ByeBell app at https://byebell.com and the code in this repository.
